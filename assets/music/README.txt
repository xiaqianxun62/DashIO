把音频文件放在这个目录（assets/music/）即可被「音乐」页自动扫到，也可以直接在 music.php
的「上传音频」框里传，传完自动加进歌单。

规则：
  - 支持扩展名：mp3 / m4a / aac / ogg / oga / wav / flac / webm
  - 歌名、歌手优先读文件标签（mp3 的 ID3、flac / ogg 的 VORBIS、m4a 的 ilst、wav 的 INFO），
    没有标签才用文件名（下划线、连字符会替换成空格）；webm 不解析标签
  - 单文件上限 10MB，且不超过主机的 upload_max_filesize / post_max_size（页面会显示实际值）
  - 超过 10MB 的大文件：页面会自动改成分片上传（每片 10MB，主机单请求上限更小时按主机算，比如 9.9MB），
    传到服务端合并成完整文件，合并后和普通文件一样播放；合并后总大小上限 50MB
  - 10MB 以内的文件直接整包上传，不切分片
  - 同名文件存成 xxx-2.mp3，不覆盖已有文件
  - 上传后会校验扩展名 + 真实 MIME + 内容里是否含 PHP 标签，非音频一律拒绝
  - 想改名、加演唱者、调整顺序：在歌单里点铅笔编辑
  - 只想临时加一首外链歌曲，可以不改这个目录，直接在 music.php 填 URL

.tmp/ 是分片上传的临时目录（每个会话一个子目录，里面是 meta.json + p00000.part…），
合并成功或取消后会自动删掉；超过 24 小时没动静的分片会在下次上传时被清理。
部署时请确认 .tmp/ 及其中的 .htaccess 一起上传成功（有些 FTP 客户端会跳过隐藏目录）。

本目录的 .htaccess 已禁止列目录、禁止执行脚本；.tmp/ 的 .htaccess 直接拒绝一切访问。
不要往这里放 .php 之类的文件。
